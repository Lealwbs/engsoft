# Engenharia de Software - UFMG

Repositório com materiais de aula, exercícios e diagramas da disciplina de Engenharia de Software.

## Estrutura do Repositório

- `material_aulas/`: Slides e materiais de apoio (UML, Casos de Uso, Diagrama de Classes, etc.).
- `resultado_exercicio/`: Resolução do Exercício 2 (Casos de Uso e Cenários), diagramas PlantUML (`.puml`), scripts geradores e PDF.
- `exercicio_03_diagrama_classes/`: Resolução do Exercício 3 (Diagrama de Classes UML), incluindo os enunciados originais em PDF, diagrama PlantUML (`diagrama_classes.puml` / `.png`), script de automação (`generate_report.py`) e o documento final de entrega (`[Classes] Italo Leal.pdf`).
