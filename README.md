# Engenharia de Software - UFMG

Repositório com materiais de aula, exercícios e diagramas da disciplina de Engenharia de Software.

## Estrutura do Repositório

- `material_aulas/`: Slides e materiais de apoio (UML, Casos de Uso, etc.)
- `resultado_exercicio/`: Resoluções de exercícios práticos, diagramas PlantUML (`.puml`), scripts geradores e PDFs.
